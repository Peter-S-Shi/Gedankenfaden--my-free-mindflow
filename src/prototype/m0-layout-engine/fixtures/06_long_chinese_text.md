# Layout Sample 06 — Long Chinese Text

- 这是一个用于测试长中文文本节点自动换行、真实尺寸测量和布局空间分配是否一致的一级主题
  - 当节点文字明显超过普通短标签长度时，布局引擎不应该仍然把它当作固定宽高的小矩形处理
    - 如果文本在界面中已经自动换成多行，那么父子距离、兄弟间距和连线锚点也应该基于换行后的真实几何尺寸重新计算
  - 这个分支故意包含多条长度接近但语义不同的中文句子，用来观察 sibling spacing 是否足够稳定
    - 第一条较长文本用于验证连续中文字符在没有空格的情况下也可以合理断行
    - 第二条较长文本用于验证多行节点不会和相邻兄弟节点发生纵向覆盖或者视觉挤压
    - 第三条较长文本用于验证导出 SVG PNG JPEG 后的节点尺寸和应用内看到的节点尺寸保持一致
- 第二个一级主题故意比较短
  - 短节点
  - 另一个短节点
- 第三个一级主题再次加入长文本，以检查真正的 bilateral balance 是否按照 subtree footprint 而不是简单按照节点数量分配左右两侧
  - 如果这一整棵子树因为长文本而占据更大的视觉高度或面积，平衡算法应该把这种视觉重量考虑进去
